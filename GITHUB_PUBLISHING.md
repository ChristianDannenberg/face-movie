# Publishing this as your first GitHub fork

1. Open the upstream repository: https://github.com/leachiM2k/face-movie
2. Click **Fork** and create the fork under your GitHub account.
3. Clone your fork to your computer.
4. Copy the files from this cleaned project into the cloned fork.
5. Review `git status`. Generated files, MP4s, caches and personal photos should not appear.
6. Commit the extension, for example:

   `Add manual face selection, enhanced detection and photo exclusion`

7. Push the commit to your fork.
8. In the GitHub repository description, you can use:

   `Face-Movie fork with manual face selection, enhanced detection, per-photo exclusion, manual crop fallback and configurable pauses.`

9. Optional repository topics:

   `face-morphing`, `mediapipe`, `opencv`, `photo-timelapse`, `docker`, `synology`, `privacy`

Before publishing, verify the upstream `LICENSE` file is present in your fork. A GitHub fork normally carries it over automatically.
